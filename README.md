# AI Coding Agent

## Overview

This project is an AI-powered coding agent built in **Python 3.11+**. The agent analyzes an existing code repository, understands a product requirement, identifies the relevant files, creates an implementation plan, modifies the codebase, and generates a summary of the changes.

The target repository used for this assignment is:

https://github.com/callicoder/node-easy-notes-app

---

## Features

- Repository exploration
- Automatic project analysis
- Framework detection
- AI-generated execution plan
- Automatic file selection
- Code generation and modification
- Change summary generation
- Implementation report generation

---

## Architecture

```
                User Request
                      │
                      ▼
               Repository Explorer
                      │
                      ▼
              Project Analyzer
                      │
                      ▼
                 LLM Planner
                      │
                      ▼
              File Identification
                      │
                      ▼
              Code Implementer
                      │
                      ▼
             Report Generator
```

### Components

- **main.py**
  - Entry point of the application.

- **explorer.py**
  - Scans the repository and collects project files.

- **analyzer.py**
  - Analyzes the repository structure and generates project context.

- **planner.py**
  - Creates an execution plan using the LLM.

- **llm.py**
  - Handles communication with the language model.

- **implementer.py**
  - Applies the required code modifications.

- **report.py**
  - Generates a summary of the implementation.

- **prompts.py**
  - Stores prompt templates used by the AI agent.

- **config.py**
  - Stores application configuration.

---

## Agent Workflow

1. User enters the repository path.
2. User provides the product requirement.
3. Repository is explored recursively.
4. Project structure is analyzed.
5. Relevant files are identified.
6. AI generates an execution plan.
7. Required files are modified.
8. A final implementation report is generated.

---

## Repository Exploration

The repository explorer scans:

- Source code files
- Configuration files
- Templates
- Static assets
- Project metadata

It automatically ignores unnecessary directories such as:

- .git
- node_modules
- __pycache__
- .venv

---

## AI Model

This project uses the **Google Gemini API** for:

- Repository understanding
- Planning
- File selection
- Code generation
- Change summarization

> **Note:**  
> API keys are intentionally **not included** in this repository for security reasons. You must provide your own Gemini API key before running the project.

---

## Assumptions

- The repository is available locally.
- The user provides a valid repository path.
- The AI model has access to the required API.
- Existing application functionality should remain unchanged.

---

## Trade-offs

- Large repositories may require additional processing time.
- Code quality depends on the responses generated by the LLM.
- API availability and quota limits may affect execution.

## Installation

Clone the repository:

```bash
git clone https://github.com/<your-username>/ai-coding-agent.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Configure your API key.

Example:

```python
GEMINI_API_KEY="YOUR_API_KEY"
```

---

## Running the Agent

```bash
python main.py
```

Example:

```
Enter repository path:
C:\Users\YourName\Downloads\node-easy-notes-app

Enter user request:
Improve the application so users can better organise and search their notes.
```
